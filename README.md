# Wunderland for Symbian
A native client for [Wunderland Store](https://github.com/WunderWungiel/Wunderland-Store), based on [AppList](https://github.com/WunderWungiel/Wunderland-Client) by schumi1331.
The source code is mostly rebranded AppList with several changes to make transition possible.

Big thank you to schumi1331. Without his work, this app would not exist.

Web version: https://ovi.wunderwungiel.pl (also accessible via HTTP)
